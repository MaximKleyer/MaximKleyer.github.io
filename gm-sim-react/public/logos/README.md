# Team logo overrides

Drop a PNG here named after a team's abbreviation and the game uses it
instead of the generated crest — for example:

    logos/SEN.png
    logos/G2.png
    logos/NAVI.png

Square images around 128x128 look best (they render at 14-40px). Any
team without a file keeps its generated crest, so partial coverage is
fine — the fictional tier-2 clubs have no real logos anyway.

Real organisation logos are trademarks. Whether to add them to a public
repository is your call, which is exactly why this folder ships empty.
